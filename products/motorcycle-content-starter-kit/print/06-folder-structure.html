Folder Structure Template

Organize footage before you edit.

OmegaGreed · Bonus PDF

How to Use

  1. Create a folder on your external drive for each month.
  2. Inside the month, create: YYYY-MM-DD - Video Project Name
  3. Copy the subfolders below into every project.
  4. Offload each camera to its matching folder the same day you shoot.
  5. Move finished exports to 10 Final / Done.

Editor Notes File (Starter)

Create 08 Notes/editor-notes.txt:

PROJECT: [Video title] MISSION: [One sentence] HOOK: [Opening line idea] STORY BEATS: - Beginning: - Middle: - End: EDITOR NOTES (spoken on ride): - THUMBNAIL: - MUSIC MOOD: - PRIORITY: [ High / Medium / Low ]

Google Drive Handoff

  1. Copy the full project folder to Google Drive.
  2. Prefix with priority: 1 - Desert Day Ride
  3. Share link + notes doc only — not your entire drive.
