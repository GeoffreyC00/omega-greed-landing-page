## HOW TO USE

1. Create a folder on your external drive for each **month**.  
2. Inside the month, create a folder for each shoot: **`YYYY-MM-DD - Video Project Name`**  
3. Copy the subfolders below into every project.  
4. Offload each camera to its matching folder the same day you shoot.  
5. Move finished exports to **10 Final / Done**.

## FOLDER DEFINITIONS

| Folder | What goes here |
|--------|----------------|
| **01 Action Camera** | POV, handlebar, mounted action cam clips |
| **02 Insta360** | 360 footage, invisible stick exports |
| **03 Pocket 3** | Gimbal / cinematic handheld |
| **04 Drone** | All aerial clips |
| **05 Main Camera** | Sony / mirrorless A-roll |
| **06 Phone** | Phone clips, timelapses, backups |
| **07 B-Roll** | Extra cutaways not tied to one camera |
| **08 Notes** | Editor notes, titles, story beats, music ideas |
| **09 Exports** | Rough cuts, previews for review |
| **10 Final / Done** | Approved final exports only |

## GOOGLE DRIVE HANDOFF

When working with an editor:

1. Copy the full project folder to Google Drive.  
2. Rename or prefix with priority number:  
   - `1 - Desert Day Ride`  
   - `2 - Vegas Ride Home`  
3. Share link + notes doc only — not your entire drive.
